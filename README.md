# 🏔️ Mountain Rush

Mountain Rush is an exciting mountain adventure game built with modern web technologies. 
Navigate through challenging mountain environments, avoid obstacles, and enjoy an engaging gaming experience directly in your browser.

## 🎮 Features

- 🏔️ Mountain-themed game environment
- 🎮 Interactive gameplay
- ⚡ Fast and responsive performance
- 💻 Works directly in the web browser
- 📱 Responsive design
- 🎨 Modern and clean user interface

## 🛠️ Technologies Used

- React
- JavaScript
- Vite
- HTML5
- CSS3
